# Infraestructura PYME

Proyecto colaborativo de documentación para el despliegue de una infraestructura LAMP con monitorización y servicios de administración para una pequeña empresa.

## Integrantes

* Ismael Gil Jiménez
* Pablo Serrano Martín

## Objetivo

Diseñar y documentar una infraestructura basada en Linux, Apache, MariaDB/MySQL y PHP (LAMP), incluyendo aspectos de seguridad, monitorización, copias de seguridad y recuperación ante desastres.

## Estructura de la documentación

* Análisis de requisitos: `docs/01-analisis.md`
* Diseño de la infraestructura: `docs/02-diseno.md`
* Planificación: `docs/03-planificacion.md`
* Instalación del servidor web: `docs/04-instalacion/servidor-web.md`
* Base de datos: `docs/04-instalacion/base-de-datos.md`
* SSH y Firewall: `docs/04-instalacion/ssh-firewall.md`
* Monitorización: `docs/04-instalacion/monitorizacion.md`
* Copias de seguridad: `docs/04-instalacion/backups.md`
* Operación y mantenimiento: `docs/05-operacion.md`
* Recuperación ante desastres: `docs/06-recuperacion.md`

## Tecnologías utilizadas

* Ubuntu Server 22.04
* Apache
* PHP
* MariaDB/MySQL
* SSH
* UFW
* Netdata
* Git y GitHub

## Control de versiones

El proyecto sigue una estrategia basada en ramas de características (feature branches), Pull Requests y revisiones cruzadas entre los miembros del equipo.
