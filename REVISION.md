# REVISION

## ¿Qué conflictos tuvisteis y cómo los resolvisteis?

Durante el desarrollo del proyecto surgieron varios conflictos debido al trabajo simultáneo sobre algunos archivos. Estos conflictos se resolvieron mediante Pull Requests y utilizando la estrategia de rebase con el comando `git pull --rebase origin main`, permitiendo integrar correctamente los cambios.

## ¿Qué comandos Git usasteis más?

Los comandos más utilizados durante el proyecto fueron:

* git add
* git commit
* git push
* git pull
* git checkout
* git checkout -b
* git pull --rebase origin main
* git push --force-with-lease

## ¿Qué haríais diferente en un próximo proyecto?

En futuros proyectos sería recomendable planificar mejor el reparto inicial de tareas y mantener una comunicación más frecuente para reducir conflictos y facilitar la integración del trabajo.

## ¿Cómo os funcionó el intercambio de roles?

El intercambio de roles permitió que ambos miembros trabajasen en todas las partes del proyecto, obteniendo una visión más completa de la infraestructura y mejorando la colaboración entre los integrantes del equipo.
